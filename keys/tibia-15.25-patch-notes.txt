Delyriumz 15.25 client patch
==========================

Patched executable:
  tibia-client-15.25.0a00a0 (1)\bin\client.exe

Login endpoint:
  http://game.delyriumzot.com:8088/login

The embedded 2048-bit RSA public modulus is in:
  tibia-15.25-client-rsa-public.txt

The matching private key is in:
  tibia-15.25-server-rsa-private.xml

IMPORTANT: configure the server with this private key before distributing
the patched client. The private key must never be placed inside the client
folder or uploaded to a public repository.

The original executable is preserved as:
  tibia-client-15.25.0a00a0 (1)\bin\client.exe.original

This patch changes the embedded login service URLs and RSA public key only.
It does not disable BattlEye or alter unrelated client protections.
